# Система автоматической проверки документов

Система для автоматической сверки документов (приказов и регламентов) с шаблонами и требованиями ТЗ с помощью LLM.

## Назначение

Проверка соответствия документов шаблонам и правилам оформления. LLM анализирует целевые документы и выявляет несоответствия, формируя отчет в формате Excel.

## Структура проекта

```
pac_4/
├── scripts/          # Скрипты парсинга и проверки
├── config/           # Конфигурация путей к документам
├── docs/             # Документация
└── results/          # Результаты проверок
```

## Типы проверок

### 1. Проверка приказов
- Сверка заголовков приказа с шаблоном
- Проверка текста документа
- Валидация метаданных (подписи, даты, город)
- Проверка плейсхолдеров

**Скрипт:** `run_order_llm_audit_v2.py`

### 2. Проверка регламентов
- Сверка структуры документа
- Проверка разделов
- Валидация категорий и таблиц
- Сверка с шаблоном регламента

**Скрипт:** `run_reg_comp_llm_audit.py`

### 3. Пакетная проверка
- Сверка номеров и дат между приказами и положениями
- Проверка соответствия должностей и ФИО
- Кросс-проверка двух комплектов документов

**Скрипт:** `run_package_llm_audit.py`

### 4. Полная проверка
Запускает все типы проверок последовательно с сохранением результатов в отдельную папку.

**Скрипт:** `run_all_llm_audit.py`

## Принцип работы

1. **Парсинг** — извлечение структурированных данных из .docx файлов
2. **Построение промптов** — формирование запросов к LLM с учетом правил ТЗ
3. **Анализ LLM** — проверка документов по правилам
4. **Формирование отчета** — сохранение выявленных несоответствий в Excel

## Конфигурация

Пути к документам задаются в `config/parser_paths.json`:

```json
[
  {
    "id": "order_version",
    "parser": "order_comp_ppu",
    "path": "путь/к/документу.docx"
  },
  ...
]
```

## Требования

- Python 3.8+
- OpenAI API key (в переменной окружения `OPENAI_API_KEY`)
- Библиотеки: `openai`, `pandas`, `python-docx`

## Результаты

Все результаты сохраняются в папке `results/` в формате Excel с полями:
- `rule_index` — номер правила
- `rule_title` — название правила
- `Целевой документ` — что найдено в документе
- `Различие` — описание несоответствия
