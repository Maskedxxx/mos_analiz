## Формат внешних данных (план)

CLI-аргумент `--external-data external.json` с содержимым:
```json
{
  "soglashenie": {"org_name": "...", "signee_name": "...", "signee_position": "..."},
  "protocol_potoka": {"flow_name": "..."},
  "dates_file": {"event_1_4_end_date": "2024-03-01", "events": [{"name": "...", "start": "...", "end": "..."}]},
  "prikaz_0_2": {"team": ["ФИО1 - должность1", ...]},
  "kpsc_current": {"indicators": [...]},
  "kpsc_target": {"indicators": [...]},
  "kpsc_ideal": {"indicators": [...]},
  "units_full": ["единица1", "единица2", ...]
}
```

## Блокеры — что запросить у менеджера

1. **Соглашение:** как получать — API Битрикс или скачивать вручную? Есть ли образец файла?
2. **Протокол выбора потока:** прислать образец DOCX
3. **Файл расчёта дат:** куда прикреплён? В архиве его нет — прислать файл
4. **Приказ 0.2:** когда появятся образцы документов?
5. **КПСЦ кросс-сверка:** нужна ли сверка значений показателей с КПСЦ-картами?
