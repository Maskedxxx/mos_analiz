# 5-я итерация: Приказ о создании ИЦ (электронный вид)

## Контекст

Документ похож на 4-ю итерацию (Приказ о создании ИЦ), но предназначен для электронного вида.
Референс реализации: `четвёртая_итерация_prikaz_ic/`

## Входные данные

| Файл | Описание | Путь |
|------|----------|------|
| Целевой документ | Документ для проверки | _указать путь_ |
| Шаблон | Эталон для сверки | _указать путь_ |
| ТЗ | Техническое задание с правилами | _указать путь_ |

## План работы

### Этап 1: Анализ целевого документа
- Открыть целевой документ
- Определить структуру: чанки, маркеры разделения
- Сравнить с документом 4-й итерации

### Этап 2: Парсер
- Если структура идентична 4-й итерации → скопировать `parser_prikaz_ic_docs.py`
- Если структура отличается → адаптировать парсер под новые маркеры

### Этап 3: Анализ шаблона
- Проверить что парсер корректно обрабатывает шаблон
- Убедиться что чанки извлекаются правильно

### Этап 4: Анализ ТЗ
- Прочитать ТЗ
- Выделить правила проверки
- Определить тип каждого правила: `target_only`, `template`, `cross_check`
- Определить scope (чанк) для каждого правила

### Этап 5: Создание правил
- Создать `config/tz_*.json` с правилами
- Формат как в 4-й итерации:
```json
{
  "правила": [
    {
      "index": 1,
      "title": "Название правила",
      "scope": "чанк",
      "compare": "target_only|template|cross_check",
      "llm": true|false,
      "content": ["инструкции для LLM"]
    }
  ]
}
```

### Этап 6: Скрипты
- Скопировать/адаптировать `run_prikaz_ic_llm_audit.py`
- Скопировать/адаптировать `test_rule.py`
- Создать `start.py`

### Этап 7: Тестирование
- Тестировать каждое правило по порядку
- Сначала на корректном файле (ожидается ok)
- Затем на файле с ошибками (ожидаются нарушения)
- Фиксировать результаты

## Структура папки (ожидаемая)

```
пятая_итерация/
├── start.py                 # Точка входа
├── config/
│   └── tz_*.json            # Правила проверки
├── documents/               # Документы для проверки
├── templates/               # Шаблоны
├── scripts/
│   ├── parser_*.py          # Парсер документа
│   ├── run_*_audit.py       # Основной аудит
│   └── test_rule.py         # Тест отдельного правила
└── logs_result/             # Результаты сессий
```

## Референс

Полная реализация 4-й итерации: `четвёртая_итерация_prikaz_ic/`
- Парсер: `scripts/parser_prikaz_ic_docs.py`
- Аудит: `scripts/run_prikaz_ic_llm_audit.py`
- Правила: `config/tz_prikaz_ic.json`
