# Инструкция по LLM-аудиту

## Запуск проверки

```bash
python start.py <имя_документа>
```

## Примеры

```bash
# Корректный документ
python start.py prikaz_ic_ok.docx

# Документ с ошибками
python start.py prikaz_ic_errors.docx
```

## Тестовые файлы

| Файл | Путь | Описание |
|------|------|----------|
| Корректный | `documents/prikaz_ic_ok.docx` | Документ без ошибок |
| С ошибками | `documents/prikaz_ic_errors.docx` | Документ с 23 ошибками |
| Шаблон | `templates/prikaz_ic_template.docx` | Эталонный шаблон |

## Результаты

После запуска создаётся папка `logs_result/session_YYYYMMDD_HHMMSS/` с:
- `audit_result.xlsx` — Excel-отчёт
- `final_results.json` — JSON с нарушениями
- `pipeline.log` — лог выполнения
- `prompts/` — отправленные промпты
- `responses/` — ответы LLM

## Тест отдельного правила

```bash
# Правило #3 на корректном файле
OPENAI_API_KEY="..." python scripts/test_rule.py --rule 3

# Правило #3 на файле с ошибками
OPENAI_API_KEY="..." python scripts/test_rule.py --rule 3 --use-errors
```

## Конфигурация

- Правила: `config/tz_prikaz_ic.json`
- API ключ: задан в `start.py` (константа `OPENAI_API_KEY`)
- Модель: `gpt-4.1-mini`
