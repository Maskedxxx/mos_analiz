# LLM-аудит: Приказ о создании ИЦ

Автоматическая проверка документа "Приказ о создании информационного центра" по 9 правилам ТЗ.

## Быстрый старт

```bash
# Проверка документа без ошибок
python start.py prikaz_ic_ok.docx

# Проверка документа с ошибками
python start.py prikaz_ic_errors.docx
```

## Структура

```
├── start.py              # Точка входа
├── documents/            # Документы для проверки
│   ├── prikaz_ic_ok.docx      # Корректный документ
│   └── prikaz_ic_errors.docx  # Документ с ошибками (тест)
├── templates/            # Шаблоны
│   └── prikaz_ic_template.docx
├── config/               # Правила проверки
│   └── tz_prikaz_ic.json
├── logs_result/          # Результаты сессий
│   └── session_YYYYMMDD_HHMMSS/
│       ├── audit_result.xlsx   # Excel-отчёт
│       ├── final_results.json  # JSON с нарушениями
│       └── ...                 # Логи, промпты, ответы
└── scripts/              # Скрипты
    ├── run_prikaz_ic_llm_audit.py  # Основной аудит
    ├── parser_prikaz_ic_docs.py    # Парсер документов
    └── test_rule.py                # Тест отдельного правила
```

## Тестовые файлы

| Файл | Описание | Ожидаемые нарушения |
|------|----------|---------------------|
| `prikaz_ic_ok.docx` | Корректный документ | 1 (имя файла) |
| `prikaz_ic_errors.docx` | Документ с ошибками | 23 |

## Правила проверки

| # | Правило | LLM |
|---|---------|-----|
| 1 | Проверка имени файла | нет |
| 2 | Проверка реквизитов в шапке | да |
| 3 | Сверка текста приказа с шаблоном | да |
| 4 | Проверка заполнения полей в тексте | да |
| 5 | Проверка элементов в приложении 1 | да |
| 6 | Проверка полей в приложении 2 | да |
| 7 | Сверка наименования компании | да |
| 8 | Проверка структуры таблицы | да |
| 9 | Проверка даты/номера в листе ознакомления | да |

## Тест отдельного правила

```bash
# Правило на корректном файле
OPENAI_API_KEY="..." python scripts/test_rule.py --rule 3

# Правило на файле с ошибками
OPENAI_API_KEY="..." python scripts/test_rule.py --rule 3 --use-errors

# Показать промпт
OPENAI_API_KEY="..." python scripts/test_rule.py --rule 3 --show-prompt
```
