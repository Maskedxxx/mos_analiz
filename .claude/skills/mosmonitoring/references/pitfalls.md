# Грабли (наступали, проверено)

## Сервисы и запуск
- **Правки не видны** — Python-бэкенды без `--reload`: после правки кода или базовых правил
  перезапускать (`scripts/restart_backend.sh`, `scripts/restart.sh`). Кастомные правила и шаблоны
  docx перечитываются на лету.
- **Без `.env` сервер проверки не стартует** — намеренно: нужны `AUDIT_LOGIN/PASSWORD/TOKEN`.
  Сообщение перечисляет незаданные переменные.
- **`set -e` в скриптах ожидания порта**: `[ … ] && break` и `code=$(curl …)` при отказе соединения
  роняют скрипт. В `scripts/` используются `if` и `|| true`; новые скрипты писать так же.
- **Docker на Mac**: порт `127.0.0.1:8081` может быть занят форвардом VS Code или локальным python —
  проверять стек через `:5174` (nginx) или изнутри сети compose.

## Модель
- Режим рассуждений Qwen оборачивает JSON в markdown — всегда `enable_thinking: false`.
- Имя модели llama.cpp игнорирует: неправильное имя не даст ошибки, отвечает загруженная.
- «Каша» в ответе (меньше вердиктов, чем правил) — штатный повтор со сменой seed, до 5.
- Вердикты при temperature 0.7 могут отличаться на 1–2 между прогонами — это не регресс;
  регресс — иное число правил или структура отчёта.

## Типы и правила
- `parser_by_ext` и `engine` вместе или ни одного — `ValueError` при загрузке конфига.
- `engine` без строки в `src/engines.py` — тип не запустится нигде; `tests/test_registry.py` ловит.
- Правило «проверить, что значение верное» без формата/согласованности — модель придумает.
- Лист присутствия: раньше читались только 10 участников — лимиты строк в парсерах xlsx
  должны идти до первой пустой строки, не до константы.

## Документы
- Word разрывает метки `{{ключ}}` на несколько фрагментов — docxtpl их не увидит; проверять grep-ом по XML.
- Текстбоксы docx (`w:txbxContent`) невидимы для python-docx; данные в них дублируются (VML + DrawingML).
- Имена файлов с кириллицей через ssh в аргументах командной строки ломаются — передавать
  скриптом или архивом (tar/base64), в скриптах брать файлы по маске.
- macOS-архивы тащат `._*` файлы — чистить после распаковки на Linux.

## Браузер
- Chrome копит зависшую очередь загрузок и перестаёт сохранять файлы — лечится только полным
  выходом из Chrome; это не дефект приложения.
- Известный отложенный дефект: в консоли при завершении аудита `"undefined" is not valid JSON`
  (слушатель ловит DOM-событие `error` у EventSource); на работу не влияет.

## Данные
- В git не попадают: `tests/data/`, `test_docs/`, `_org_store.json`, `logs_*`, `uploads/`,
  `docs/методички/` — персональные данные и тяжёлые файлы. Проверять `git status` перед коммитом.
