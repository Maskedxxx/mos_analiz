## 1. Контекст и цель

Сейчас ДВА независимых фронта на двух доменах:

| | Аудит (проверка) | Генерация |
|---|---|---|
| Репо | `~/projects/mos_analiz_refactor` | `~/projects/mos_generated` |
| Бэкенд | `:8081` uvicorn `main:app`, screen `backend8081` | `:8090` uvicorn `api:app`, screen `mosgen` |
| Фронт | React+Vite `ui-demo`, prod-build → `:5174` (`vite preview`, screen `mosaudit-ui`) | vanilla HTML `static/index.html`, отдаётся самим FastAPI по `/` |
| Домен | `https://mosaudit.ru.tuna.am` (screen `mosaudit-tuna`, `tuna http 5174 --subdomain=mosaudit --location=ru`) | `https://mosgen.ru.tuna.am` (screen `mosgen-tuna`, `tuna http 8090 …`) |
| Авторизация | cookie-логин (guest / mos186124kva) | НЕТ (открыт) |

**Цель:** один домен, левый сайдбар с пунктами «Аудит» и «Генерация». Оба сервиса уже откалиброваны — задача СОЕДИНИТЬ без регрессий, UI обоих сохранить строго как есть.

## 2. Архитектурное решение (проверено в коде)

1. **Хост-приложение = React `ui-demo`** (оно богаче: SSE-прогресс, панель правил, кастом-правила, 3-слотовая сквозная проверка).
2. **Прокси уже есть:** `ui-demo/vite.config.js` содержит `server.proxy` И `preview.proxy` для `/api` → `http://localhost:8081`. Добавляем ВТОРОЙ маршрут:
   - `/api` → `:8081` (аудит, как сейчас),
   - `/gen` → `:8090` c `rewrite: p => p.replace(/^\/gen/, '')` (генерация).
   Почему префикс: оба бэкенда отдают `/api/types/...` — без префикса коллизия.
3. **Форму генерации портируем в React** (`ScreenGeneration.jsx`) — 1:1 по поведению текущего `static/index.html`.
4. **Домен:** остаётся `mosaudit.ru.tuna.am` (туннель на 5174 не трогаем). `mosgen.ru.tuna.am` пока живёт как есть (fallback), гасим только после приёмки владельцем.
5. **Побочный эффект:** генерация оказывается ЗА логином аудита (раньше была открыта) — это улучшение, но зафиксировать как решение.

## 4. Что именно портировать в `ScreenGeneration.jsx` (полный перечень поведения)

Источник истины — текущий `mos_generated/static/index.html`. Перенести ВСЁ:

1. **Список типов:** `GET /gen/api/graph` → узлы `{doc_type, title, code, position}`; дропдаун показывает `code` + `title` + slug, отсортирован по `position`.
2. **Схема полей:** `GET /gen/api/types/{t}/schema` → `{title, fields:[{key,label,required,source,hint}]}`; рендер инпутов с меткой, звёздочкой `*` для required и тегом источника («своё»).
3. **Валидация обязательных (ФИКС от 2026-07-31):** до скачивания собрать пустые required → показать `«Заполните обязательные поля: <labels через запятую>»` и НЕ качать. Работает для КАЖДОГО типа по его схеме (не хардкод).
4. **Скачивание (ФИКС от 2026-07-31):** нативное — `GET /gen/api/types/{t}/download?<все значения>&session_id=web` через СКРЫТЫЙ iframe. Никаких blob/`<a>`/`revokeObjectURL` (тот механизм тихо не сохранял файл).
5. **Автозаполнение по ООО (фича от 2026-07-31):**
   - при открытии формы `GET /gen/api/orgs` → datalist подсказок для поля `org_full`;
   - на `change`/`blur` поля `org_full` → `GET /gen/api/org/suggest?org=<значение>` → `{field_key:[values]}`;
   - для каждого поля: заполнить первым значением, если пусто; во всех случаях наполнить datalist вариантами;
   - нормализация ООО — на бэкенде (`engine.normalize_org`: снимает юрформу/кавычки/регистр/пунктуацию), фронту ничего нормализовать не надо.
6. **Статусы:** «Генерация…», «Готово — документ скачан ✓», ошибки — красным.
