# Фикстуры для тестов спецдвижков

Папка `tests/data/` в git **не хранится** (`.gitignore`): образцы — реальные документы
предприятий с ФИО и названиями. Без образцов тесты `tests/test_smoke_special_xlsx.py`
пропускаются с пометкой «нет фикстуры».

## Что положить

По одному файлу на тип, имя всегда `sample.xlsx`:

```
tests/data/
  drivers/sample.xlsx                     1.2  Расчёт драйверов
  forma_0_3/sample.xlsx                   0.3  Форма «О предприятии в цифрах»
  forma_0_4/sample.xlsx                   0.4  Форма «О проекте в цифрах»
  kartochka_proekta_0_2/sample.xlsx       0.2  Карточка проекта
  kartochka_proekta_2_4/sample.xlsx       2.4  Утверждённая карточка проекта
  kpsc/sample.xlsx                        2.1  КПСЦ и Спагетти ТС
  list_prisutstviya_modul_1/sample.xlsx   3.1  Лист присутствия (модуль 1)
  plan_grafik/sample.xlsx                 2.6  План-график
```

## Откуда взять

Архив `ПЕРЕДАЧА_фикстуры_тестов.zip` передаётся вместе с проектом отдельно от репозитория.
Распаковать в корень проекта — структура выше получится сама.

Подойдёт и любой собственный документ нужного типа: тест проверяет только то, что движок
доходит до конца и не оставляет в отчёте статусов `ERROR`/`MISSING`, а не соответствие правилам.
