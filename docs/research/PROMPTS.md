## 1. Обзор

Vision Pipeline использует GPT-4.1-mini для двух задач:
1. **Извлечение текста** из изображений страниц документа
2. **Классификация** текста по чанкам

Промпты оптимизированы для:
- Русскоязычных документов
- Официального стиля (приказы, регламенты)
- Таблиц и структурированных данных

## 3. User Prompts

### 3.1 Prompt для извлечения текста (одна страница)

```python
def build_extraction_prompt(page_num: int, total_pages: int) -> str:
    """
    Формирует промпт для извлечения текста со страницы.

    Args:
        page_num: номер текущей страницы
        total_pages: общее число страниц

    Returns:
        Текст промпта
    """
    return f"""Извлеки весь текст с этого изображения страницы документа.

КОНТЕКСТ:
- Страница {page_num} из {total_pages}
- Документ на русском языке
- Тип документа: официальный приказ

ИНСТРУКЦИИ:
1. Прочитай весь текст на изображении
2. Сохрани форматирование (заголовки, пункты, таблицы)
3. Верни результат в JSON формате

Если страница содержит таблицу, представь её как:
| Колонка1 | Колонка2 | Колонка3 |
| значение | значение | значение |

Начинай извлечение."""
```

### 3.2 Prompt для классификации на чанки

```python
def build_chunking_prompt(full_text: str, chunk_config: dict) -> str:
    """
    Формирует промпт для разбиения текста на чанки.

    Args:
        full_text: полный текст документа
        chunk_config: конфигурация чанков с маркерами

    Returns:
        Текст промпта
    """
    markers_text = "\n".join([
        f"- {name}: маркер = \"{marker}\"" if marker else f"- {name}: от начала"
        for name, marker in chunk_config["markers"].items()
    ])

    return f"""Разбей следующий текст документа на чанки.

МАРКЕРЫ ЧАНКОВ:
{markers_text}

ТЕКСТ ДОКУМЕНТА:
---
{full_text}
---

ИНСТРУКЦИИ:
1. Найди каждый маркер в тексте
2. Извлеки текст от маркера до следующего маркера
3. Для первого чанка (шапка) — от начала до первого маркера
4. Верни JSON с чанками

Верни результат."""
```

### 7.2 Python загрузчик

```python
from typing import Dict, Any
import json
from pathlib import Path

class PromptConfig:
    """Конфигурация промптов для Vision Pipeline."""

    def __init__(self, config_path: str):
        with open(config_path, 'r', encoding='utf-8') as f:
            self.config = json.load(f)

        self._load_prompts()

    def _load_prompts(self):
        """Загружает промпты из конфигурации."""
        # Системные промпты
        self.system_prompt_extraction = globals().get(
            self.config["extraction_prompt"]["system"],
            SYSTEM_PROMPT_EXTRACTION
        )
        self.system_prompt_chunking = globals().get(
            self.config["chunking_prompt"]["system"],
            SYSTEM_PROMPT_CHUNKING
        )

        # User prompt template
        self.user_prompt_template = globals().get(
            self.config["extraction_prompt"]["user_template"],
            ""
        )

    def get_extraction_prompt(self, page_num: int, total_pages: int) -> Dict[str, str]:
        """Возвращает промпты для извлечения текста."""
        user_prompt = self.user_prompt_template + f"\n\nСтраница {page_num} из {total_pages}."

        return {
            "system": self.system_prompt_extraction,
            "user": user_prompt
        }

    def get_chunking_prompt(self, full_text: str) -> Dict[str, str]:
        """Возвращает промпты для разбиения на чанки."""
        user_prompt = build_chunking_prompt(full_text, self.config)

        return {
            "system": self.system_prompt_chunking,
            "user": user_prompt
        }

    @property
    def markers(self) -> Dict[str, str]:
        """Маркеры для чанков."""
        return self.config.get("markers", {})

    @property
    def required_chunks(self) -> list:
        """Обязательные чанки."""
        return self.config.get("required_chunks", [])
```

## 8. Примеры использования

### 8.1 Полный пример извлечения

```python
from openai import OpenAI
import base64

# Инициализация
client = OpenAI()
config = PromptConfig("config/chunks_config.json")

# Загрузка изображения
with open("page_001.png", "rb") as f:
    image_base64 = base64.standard_b64encode(f.read()).decode()

# Получение промптов
prompts = config.get_extraction_prompt(page_num=1, total_pages=5)

# Вызов API
response = client.chat.completions.create(
    model="gpt-4.1-mini",
    messages=[
        {"role": "system", "content": prompts["system"]},
        {
            "role": "user",
            "content": [
                {"type": "text", "text": prompts["user"]},
                {
                    "type": "image_url",
                    "image_url": {
                        "url": f"data:image/png;base64,{image_base64}",
                        "detail": "high"
                    }
                }
            ]
        }
    ],
    max_tokens=4096,
    temperature=0.0
)

# Парсинг ответа
result = json.loads(response.choices[0].message.content)
print(result["page_text"])
```

## 9. Рекомендации по оптимизации

### 9.1 Оптимизация качества

| Проблема | Решение |
|----------|---------|
| Пропущенный текст | Увеличить DPI до 300, использовать detail="high" |
| Ошибки в таблицах | Добавить специальный промпт для таблиц |
| Неверное разбиение | Уточнить маркеры в конфигурации |
| Нечитаемые сканы | Увеличить DPI, retry с detail="high" |

### 9.2 Оптимизация стоимости

| Метод | Экономия |
|-------|----------|
| detail="low" для preview | ~90% токенов |
| Объединение страниц | Меньше запросов |
| Кэширование | Повторное использование |
| Батчинг | Оптимизация API лимитов |

### 9.3 Оптимизация скорости

| Метод | Эффект |
|-------|--------|
| Параллельные запросы | 5x ускорение |
| Предварительная конвертация | Кэш изображений |
| Меньший DPI (150) | Быстрее конвертация |
| Асинхронный код | Лучшее использование I/O |
